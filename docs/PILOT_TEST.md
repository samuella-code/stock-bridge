# Retailer pilot test
Test with 5–10 consenting retailers for 7–14 days. Do not collect unnecessary personal data.

## Session tasks
1. Sign up without help.
2. Add five real products.
3. Record a sale and expense.
4. Find a low-stock item.
5. Explain the restocking recommendation.
6. Correct a mistaken sale.
7. Use the app on their normal phone.

## Record
Retail category, device, task success, time, confusion, bugs, requested features, daily usage and willingness to pay. Never record passwords or customer details.

## Success targets
At least 80% complete core tasks without help; at least 60% return in week two; zero cross-business data exposure; retailer can explain the reorder recommendation; top three problems are fixed before wider launch.
